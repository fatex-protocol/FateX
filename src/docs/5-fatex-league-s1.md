## FateX League S1 Reward Rules

### Leaderboard Airdrop Rewards
- **GROW Reward Pool (Dynamic Growth)**: Scales with total network Grow votes:
  - ≤ 1B Grow votes: 5% (e.g., 1B = 50M GROW)
  - 1B-2B: 6% (e.g., 2B = 120M GROW)
  - 2B-3B: 7%
  - 3B-4B: 8%
  - 4B-5B: 9% (e.g., 5B = 450M GROW)
  - > 5B: Fixed at 9%
- **Allocation Rules** (Leaderboard participation required):
  - Rewards are calculated based on the combined weight of Grow/RGAS value and Fate/RGAS value:
    1. **Grow Value Share** = (Your Grow vote value ÷ Total network Grow vote value)
    2. **Fate Value Share** = (Your burned Fate value ÷ Total network burned Fate value)
    3. **Total Weight** = Grow Value Share + Fate Value Share
    4. Your GROW = Total Weight ÷ Sum of All Users’ Total Weights × GROW Reward Pool
  - **Weight Adjustments**: Grow and Fate weights are set by admins to ensure fairness.
  - **Example**:
    - Network: 2B Grow vote value, 100K Fate value, 120M GROW pool.
    - User A: 200M Grow vote value, 1,000 Fate value.
    - Grow Value Share = (200M ÷ 2B) = 10%, Fate Value Share = (1,000 ÷ 100K) = 1%.
    - Total Weight = 10% + 1% = **11%**.
    - If total weights sum to 100%, User A gets: 120M × 11% ≈ **13.2M GROW**.
- **Claim Time**: Opens after the event ends, one claim per user.
